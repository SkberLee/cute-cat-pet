# 电子宠物猫 · 第一版设计规格

**日期：** 2026-11-03  
**引擎：** Godot 4.7（实测 4.7.2）  
**平台：** Android 优先  
**受众：** 送礼向，给女生玩的单人治愈养猫

## 1. 产品定位

单人、离线、偏写实萌宠 3D 的电子宠物。轻养成 + 治愈日常：摸、喂、逗即可建立亲密度。不惩罚、不死亡、不氪金。第一版只有一只猫、一个小房间。

## 2. 体验目标

她打开游戏后 10 秒内能摸到猫，并感到「这只猫在回应我」。数值服务于情绪反馈，不做成任务列表。

## 3. 场景与镜头

- 一个温馨室内小房间（床/窗/地毯等可先用简单几何体占位）
- 一只猫在房间中心附近可活动的小范围
- 固定或轻缓跟随的第三人称机位，FOV 与距离适合手机竖屏或横屏（第一版默认横屏，便于 3D 观察；若后续要竖屏再改 UI）
- 操作以点按 UI 按钮 + 点击猫身为主

## 4. 核心循环

进房看猫 → 摸头 / 喂食 / 逗玩 → 心情、饥饿、亲密度变化 → 猫用动画与短句反馈 → 想再打开看一眼

## 5. 数值（软养成）

三项，范围均 0.0–100.0：

| 名称 | 含义 | 自然变化 | 边界行为 |
|------|------|----------|----------|
| mood（心情） | 开心程度 | 缓慢下降 | 低时更想被摸，不会游戏结束 |
| hunger（饥饿） | 越高越饿 | 缓慢上升 | 高时求食动画/提示，不会死亡 |
| bond（亲密度） | 和主人的黏人程度 | 几乎不自然降；互动上升 | 达到阈值解锁更黏的短句/动作 |

UI：默认用表情或柔和进度点暗示，不强制大数字；调试期可显示数值条。

## 6. 三件互动

1. **摸头（pet）**  
   - 点击猫头部或「摸摸」按钮  
   - mood↑、bond↑；播放眯眼/呼噜类反馈  
2. **喂食（feed）**  
   - 「喂食」按钮；hunger↓；过饱时懒洋洋；hunger 高时轻求食  
3. **逗玩（play）**  
   - 「逗逗」按钮或简单逗猫棒点击；短互动后 mood↑、bond↑  

冷却：同一动作可连续，但短冷却（约 0.8–1.5s）避免刷爆动画。

## 7. 明确不做（第一版）

狗、多宠物、多房间、商店/内购、复杂剧情、联机、惩罚性死亡、重度 RPG 数值。

## 8. 技术架构（原型）

- 项目路径：`/workspace/cute-cat-pet`
- Godot 4.7.2，3D Forward+ 或 Mobile 渲染（Android 用 Mobile）
- 主场景：`res://scenes/main.tscn`（房间 + 猫 + UI）
- 脚本：
  - `scripts/pet_stats.gd`：三项数值与自然衰减/增长
  - `scripts/cat_controller.gd`：接收 pet/feed/play，播反馈、改数值
  - `scripts/main_ui.gd`：三个按钮 + 软状态显示
- 资源：第一版用 CSG/简单 Mesh + AnimationPlayer 或程序化 bob 占位；预留替换写实猫模型（glTF）的节点路径
- 导出：Android 预设稍后配置；原型先在编辑器/桌面跑通逻辑

## 9. 成功标准（原型可验收）

1. 打开主场景可见房间与猫占位  
2. 三个按钮均可点，数值按设计变化  
3. 互动有可见反馈（缩放弹跳、颜色闪、或短动画 + 一句中文旁白/标签）  
4. hunger/mood 随时间缓慢变化（进程内 Timer）  
5. 工程可在 Godot 4.7.2 无报错打开

## 10. 后续（非本原型）

替换写实猫模与动画、房间美化、竖屏 UI、安卓正式导出与签名、亲密度里程碑装扮。
